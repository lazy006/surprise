# Birthday surprise
1. Photos: put 13 images in assets/photos/ named photo-01.jpg ... photo-13.jpg
2. Video: put your file at assets/video/our-video.mp4
3. Text, captions, passkey: edit the CONFIG block at the top of script.js
4. Publish: push this folder to a GitHub repo > Settings > Pages > Deploy from branch (main, / root)
